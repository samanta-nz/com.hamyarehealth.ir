# همیار سلامتی من — com.hamyarehealth.ir

اپِ اندرویدِ **آرامش، سلامتی و ذهن‌آگاهی**، ساخته‌شده روی همان موتورِ «همیار من».
بستهٔ مستقل، نشان (آیکون) اختصاصی، رابط کاربری اختصاصی — ولی محتوا، حساب کاربری و
مخزنِ رسانه **همان زیرساخت قبلی** است تا چیزی از کار نیفتد.

## چه چیزی از اپ «همیار من» کپی شده است؟

تمام **کارت‌ها، منوها، زیرمنوها و لینک‌های باکت** مربوط به سلامتی و آرامش،
دقیقاً با همان منطق:

* **سلامتی** — پیشرفت سلامتی، چرخه ماهانه، یوگا، ورزش عمومی، آب و تغذیه، خواب،
  یادآور دارو، روتین امروز، تقویم/علائم چرخه، تنفس پیش از خواب.
* **کسب آرامش** — تنفس (۶ تمرین)، آرام‌سازی عضلانی، سفر ذهنی، تصویرسازی، قصه‌ها،
  صداهای آرام (پلیرِ کاملِ روی باکت)، دفترچهٔ شکرگزاری و ژورنال.
* **ذهن‌آگاهی** — حضور ذهن، خودهیپنوز سالم (مطالعه/امتحان/فکر/رابطه/خواب)،
  تمرین‌های کوتاه، سؤال خودشناسی روزانه با ذخیره و همگام‌سازی.
* **فضای امن من** — نوشتن آزاد، دفترچه‌ها، کتاب شعر، آلبوم امن، شماره‌های کمک.
* **محتوا** — کاتالوگ `assets/content/*` و فایل‌های تعاملیِ روی باکت
  (`https://c539776.parspack.net`) با همان مسیرها، همان رمز `HMK1` و همان کلید
  `html_media_key`؛ هیچ نشانی‌ای عوض نشده است.

* **تقویم** — همان صفحهٔ «تقویم» اپ قبلی (شمسی/قمری/میلادی + مناسبت‌های ماه) که در
  این اپ بدون تب‌های مدرسه باز می‌شود؛ به‌همراه ساعتِ آنالوگ و کارتِ تاریخ/ساعتِ
  داشبورد که عیناً از اپ قبلی منتقل شده‌اند.

بخش‌های مدرسه/آزمون/ابزار/آشپزی/نقاشی در مسیرهای این اپ نیستند (تب‌ها:
**داشبورد · سلامتی · کسب آرامش · ذهن‌آگاهی · بیشتر**). موتورهای مشترکِ محتوا و پخش
(`ui/study`, `ui/content`, `ui/calmdown`) عیناً سرِ جای خودشان‌اند چون همین بخش‌های
سلامتی از آن‌ها استفاده می‌کنند؛ کدهای بی‌استفاده در APK نهایی با R8 حذف می‌شوند.

## ورود و ثبت‌نام

منطقِ ورود/ثبت‌نام **همان** منطقِ همیار من است (Appwrite + Google native sign-in +
جدولِ `student_profiles` + آینهٔ محلی). تنها تفاوت‌ها:

* عنوان فرم: «ثبت‌نام همیار سلامتی من» و فیلدِ نمایشیِ **اپ** که همان
  `BuildConfig.APP_TITLE` است تا معلوم باشد این حساب از کدام اپ ساخته می‌شود.
* انتخابِ آیکونِ دختر/پسر حذف شده (این اپ یک نشانِ واحدِ قلب/نبض دارد)، پس
  دیالوگِ «راه‌اندازی دوباره برای تغییر آیکون» هم برداشته شده است.
* `GRADE_ID` عمداً همان `grade9` مانده تا تابعِ سرورِ `user-bootstrap`
  (قفلِ ایمیل/پایه/سقف دو دستگاه) کاربرانِ فعلی را مسدود نکند. کانالِ آپدیت
  مستقل است: ردیفِ `app_release_health`.

## ساخت

```bash
./gradlew :hamyar-health:assembleRelease      # APK انتشار
./gradlew :hamyar-health:testDebugUnitTest    # تست‌های واحد
```

هر push روی `main` ورک‌فلوی `.github/workflows/release-health.yml` را اجرا می‌کند:
تست → کامپایل → `assembleRelease` → بررسی بسته/امضا → GitHub Release (`health-vX.Y.Z`)
→ آپلود روی ParsPack در `apk/health/…`. برای نسخهٔ تازه فقط `versionCode` و
`versionName` را در `apps/hamyar-health/build.gradle.kts` بالا ببر.

**کلیدهای ParsPack** (اختیاری، فقط برای آپلود APK): `PARSPACK_ACCESS_KEY` و
`PARSPACK_SECRET_KEY` را در Secrets همین مخزن بگذار؛ بدون آن‌ها بیلد و GitHub Release
انجام می‌شود و مرحلهٔ آپلود با هشدار رد می‌شود (مخزنِ محتوا عمومی است و برای *کارکرد*
اپ نیازی به کلید نیست).

## ساختار

```
apps/hamyar-health/        اپ (MainActivity، ناوبری، صفحه‌ها، UI اختصاصی)
  ui/health/               داشبورد و زبان تصویری این اپ (Hero/کارت‌ها/کاشی‌ها)
  ui/hub/                  هاب سلامتی، ذهن‌آگاهی، گزارش روزانه، دارو
  ui/calmdown/  ui/wellness/   کسب آرامش، تمرین‌ها، پلیرِ صداهای آرام
  ui/content/              کاتالوگِ تعاملی (یوگا/ورزش/تنفس/آموزش‌ها)
  ui/cycle/  ui/water/  ui/routine/  ui/safespace/  ui/settings/
  res/                     آیکون اختصاصی (قلب + نبض)، رنگ‌ها، تم
shared/core-common         ابزارها (تاریخ جلالی، TableIds، LocalStore، Helplines)
shared/core-designsystem   تم/پالت/کامپوننت‌های مشترک
shared/core-appwrite       Auth، TablesDB، Storage، توابع سرور
shared/core-security       قفل PIN/الگو، بیومتریک، رمزگذاری
shared/core-notifications  یادآورها، کانال‌ها، ساعات سکوت
shared/core-sync           صف outbox همگام‌سازی
shared/feature-*           پیوند، حرف دل، تماس، پخش، بسته‌های مطالعه
```
